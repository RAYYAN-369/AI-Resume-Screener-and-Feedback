About this project

Built to make ATS feedback available before you apply, not after you get silence.

AI Resume Scanner is a resume ↔ job description matcher built for the AI / GenAI Fellowship Program. It runs entirely on locally hosted infrastructure , no paid AI API, no resume data leaving the machine it's running on.

Mission & vision

Most applicant tracking systems reject resumes on keyword and formatting mismatches long before a human reads them, and candidates rarely find out why. Our mission is to surface that feedback earlier: an evidenced match score, the specific skills a posting expects that a resume doesn't show, and concrete, section-by-section suggestions , so the decision to apply, and how to present the application, is an informed one.

The longer-term vision is a scanner that's honest about its limits: it's guidance from a language model reading two documents, not a hiring decision, and the interface says so throughout.

System architecture

Five components, each doing one job, chained into a single /upload request.

FastAPI

Serves the site and exposes the /upload endpoint that the whole scan runs through.

Resume & JD extraction

PyPDF and python-docx turn uploaded PDFs and DOCX files into plain text.

ATS engine

Normalizes and compares resume and job-description text against a curated skills list to compute a match score.

Prompt builder

Assembles a strict, schema-constrained prompt so the model returns predictable, parseable JSON.

Ollama

Runs the language model locally llama3.2:3b by default and returns the structured assessment.

JSON validation

A Pydantic schema checks every field and score range before anything reaches the frontend.
