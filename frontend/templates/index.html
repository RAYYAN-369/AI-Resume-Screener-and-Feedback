How a scan works

Six steps, entirely automated, from file upload to a structured report.

  1. Upload your resume

    Drop in a PDF or DOCX — it's parsed on the server that's running this app, not sent to a third party.

  2. Add the job description

    Paste the text directly, or upload the posting as a PDF or DOCX file.

  3. Text extraction

    PyPDF and python-docx pull clean text out of both documents.

  4. ATS keyword matching

    The resume is checked against a curated technical-skills list to compute matched and missing skills.

  5. AI review via Ollama

    A locally hosted model reads both documents against a structured prompt and returns strict JSON.

  6. Results dashboard

    The validated response renders as scores, skill gaps, and section-by-section feedback.

Frequently asked questions

The specifics of how the scan runs and what it does with your files.

Is my resume stored or sent anywhere?

No. There's no paid or external AI API in the loop — analysis runs through a locally hosted Ollama model, and your files are used for the scan you run, not kept for anything else.

What resume and job description formats are supported?

PDF and DOCX for both the resume and the job description. You can also paste the job description as plain text instead of uploading a file.

Is the ATS score identical to what a real company's ATS would give?

No single standard exists across real ATS platforms. This score is a reasonable approximation that blends keyword matching with an AI review — treat it as directional, and weigh the specific feedback more than the exact number.

Do I need an internet connection to run a scan?

No. The AI model runs locally through Ollama, so no paid API key or outbound API call is required once the model is downloaded.

What happens if the Ollama server isn't running?

The backend returns a readable error instead of crashing, so you'll know to start the Ollama server rather than seeing a broken page.

Do I need a GPU to run this?

No — it runs on CPU with a small model such as qwen2.5:1.5b or llama3.2:3b. A GPU will make each scan faster, but it isn't required.

Ready to see where your resume stands?

Two files and about a minute — a match score, skill gaps, and section-by-section feedback.
