Privacy Policy

Last updated: 2026 — v0.1.0 (MVP)

This policy describes what actually happens to your files when you use AI Resume Scanner. It's written for a student fellowship project, not a commercial product if you plan to deploy this publicly or commercially, have it reviewed properly; nothing here is legal advice.

What we collect

  • The resume file you upload (PDF or DOCX).
  • The job description you paste or upload (PDF or DOCX).
  • No account, name, or persistent identity is required to run a scan.

How files are processed

Uploaded files are saved temporarily on the server running the application, text is extracted with PyPDF or python-docx, and that text is sent to a locally hosted Ollama model for analysis. No external, paid, or third-party AI API is called at any point — the model runs on the same machine as the backend.

What we don't do

  • We don't sell, share, or transmit your resume content to third parties.
  • We don't use your files to train any model.
  • We don't run analytics trackers or advertising scripts on this site.

Storage & retention

Uploaded files are written to a local uploads/ folder on the server for processing. Because this is an MVP without a scheduled cleanup job, treat any given deployment's retention as implementation specific and check with whoever is operating the instance you're using if that matters to you, or run the project yourself for full control.

Your resume, your decision

Analysis results are AI-assisted guidance from a language model reading two documents not a hiring decision, and not a guarantee of how any specific employer's systems will score your resume.

Changes to this policy

This policy may change as the project develops. Check this page for the current version before relying on it.

Contact

Questions about this policy can go through the contact page or the project's GitHub repository.
